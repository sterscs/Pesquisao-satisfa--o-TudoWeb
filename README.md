Pesquisa de Satisfação - TudoWeb

# Sobre o projeto

Este projeto foi desenvolvido em Python para a empresa fictícia TudoWeb, com o objetivo de realizar uma pesquisa de opinião para avaliar o grau de satisfação dos clientes com o atendimento prestado.

O programa coleta informações dos entrevistados e contabiliza as respostas sobre a qualidade do atendimento.

# Objetivo

Praticar os conceitos básicos de programação em Python, utilizando estruturas de repetição e decisão para coletar, analisar e exibir os resultados de uma pesquisa.

# Funcionalidades

Coleta o nome do entrevistado.

Solicita a idade do entrevistado.

Registra a opinião sobre o atendimento.

Realiza a pesquisa com 50 entrevistados.

Conta a quantidade de respostas "EXCELENTE".

Conta a quantidade de respostas "RUIM".

Exibe o resultado final da pesquisa.
